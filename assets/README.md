# Framework figure

`overview.png` and `overview.pdf` are the existing framework figure from the accompanying PriorReview manuscript. The PDF is the same figure referenced by the manuscript as `Fig2.pdf`; its caption is "Overview of the PriorReview framework."

The image includes the historical-prior construction stage as scientific context. The code in this repository covers the review runtime; the offline construction pipeline is not part of this package.

The artwork was copied without modifying its labels or content. The PNG is used by the repository README; the PDF provides the vector version for zooming.
